# Task4 机械臂运动学方程推导（考核方向内 10%）

> 本任务**不需要写代码**，是纯推导 + Word 文档任务。

## 考核要求（原文）
> 进行机械臂的运动学正解和逆解，推导此机械臂的运动学方程，并在 word 中打出(typing)公式推导，请不要手写和截图，提交的文件必须是 word 类文档，否则 0 分。

- **格式**：Word 文档，公式用**打字输入**（Word 公式编辑器 / 域代码 / LaTeX 转 Word），严禁手写拍照、严禁截图，否则 0 分

## 推导提纲（建议章节）
1. **机构参数定义**
   - 各连杆长度 L1（后臂）、L2（前臂）；基座转角 θ0；后臂角 θ1；前臂角 θ2（相对后臂）；夹爪长度不计或简化
   - 坐标系定义与正方向约定
2. **运动学正解（Forward Kinematics）**
   - 给定 4 个舵机角度 (θ0, θ1, θ2, 爪), 求末端执行器（笔尖/夹爪中心）在纸面上的坐标 (x, y, φ)
   - 平面内：x = L1·cos(θ1) + L2·cos(θ1+θ2)（叠加前臂相对角）；基座：整体绕 z 旋转 θ0
   - 写出矩阵形式或三角形式，**逐式推导**
3. **运动学逆解（Inverse Kinematics）**
   - 给定目标坐标 (x, y)，求关节角：
     - 几何法：余弦定理求 θ2，再求 θ1（atan2）
     - 说明多解情况（肘上/肘下）与选解规则（例如选"前臂朝前"解、避开限位）
   - 基座角 θ0 = atan2(y, x)
4. **工作空间分析（加分项）**
   - 可达范围、奇异点（臂伸直时）、限位对工作空间的影响
5. **结论与验证**
   - 用一组数值代入正解→逆解验证闭环

## 与 Task5 的关系

推导完成后，把公式填入 `..\Task5\Task5.ino` 中的 `solveIK()`，即可驱动绘图。
