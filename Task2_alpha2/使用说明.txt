Task2_alpha2 使用说明

基础：沿用 JoyFK_alpha2 的舵机 D9/D8/D7/D6、摇杆 A3/A2/A1/A0、
方向、90度开机角度、20ms/度速度，以及腕点运动学正解。
限位：底座0~180，上臂45~160，前臂30~110，夹爪5~130度。
坐标单位mm：L1=38、L2=80、L3=80；这里显示的是腕点，不是夹持中心。

1. Arduino IDE 打开本目录 Task2_alpha2.ino，选择实际主控板与端口后烧录。
   本次已按 Arduino Uno 编译检查；没有向设备烧录，也未进行实物抓放测试。
2. 串口监视器选择9600，行结束选择“换行”或“回车和换行”。
3. 开机可直接用摇杆控制，自动输出坐标及 b/r/f/c 四个舵机指令角度。
   POS 单次查询；LIVE 切换周期输出；H加速，L减速。
4. 点位目前均为占位值，A/B/C对应的四点未标定时不会启动自动动作。

标定示例（以A为例，B、C同样操作）
  用摇杆到达待机位置，发送 SET HOME。
  到达物体A抓取位置，发送 SET A PICK。
  到达抓取位置上方、可带物体通过的位置，发送 SET A PICKUP。
  到达A的放置位置，发送 SET A PLACE。
  到达放置位置上方，发送 SET A PLACEUP。
  摇杆调整夹爪到合适张开角度，发送 SET A OPEN。
  摇杆调整夹爪到合适夹紧角度，发送 SET A CLOSE。
  要求张开角度小于夹紧角度；默认占位张开5、夹紧120，均可按物体单独标定。
  TABLE 或 ? 可查看所有点位的坐标、角度和标定状态；15/15表示四点全部记录。
  确认抓取与放置在x、y方向均有明显位移，且A/B/C三个放置位置明显不同。
  检查抓取上方点、放置上方点及待机位之间整段运动的空间，不能只看端点高度。

执行
  发送 A/B/C：回待机（夹爪保持）→抓取上方→张开→抓取点→夹紧→
  抓取上方→放置上方→放置点→张开→放置上方→待机（保持张开）。
  动作使用保存的关节角度同比例插值，步间非阻塞；各阶段到达后等待300ms。
  坐标用于标定与核对，不做逆解，不保证末端沿直线移动。
  自动动作期间不接受摇杆、改点或其他抓放指令；不会排队执行。
  X 加回车：中止自动动作并保持当前角度，舵机仍有保持力。
  完成或中止后摇杆暂时禁用，发送 M 恢复摇杆，A/B/C可直接启动下一次动作。

保存标定结果
  SET只写入内存，断电、复位或串口连接引起的主控复位后会丢失。
  发送 TABLE，复制每个点的b/r/f/c角度到代码顶部 PLACEHOLDERS 对应项，
  待机位填入 HOME_ANGLES，夹爪角度填入 OPEN_ANGLES/CLOSE_ANGLES。
  将已完成标定物体的 INITIAL_TAUGHT 项设为15，重新编译烧录即可固定保存。
  坐标会由这些角度自动重新计算，无需另填x/y/z；尚未标定的物体保留0。

说明
  A/B/C物体定义及摆放由实物决定，软件不会自动识别物体或检测是否抓牢。
  当前坐标来自指令角度计算，舵机无位置反馈，需结合实物校准。
  原 Task2 和 JoyFK_alpha2 工程均保留。
