任务五 四按键使用说明
====================
（第二块 UNO R3 独立烧录 KeypadBoard_Task5.ino；主控板烧 Task5_LineN.ino）

一、接线
------------------------------------------------------------
按键引脚：键1→D8  键2→D9  键3→D10  键4→D11
接线方式：按键一端接对应引脚，另一端接 GND（代码已用内部上拉，无需外部电阻）

两板连接：
  按键板 TX(D1) → 主控板 RX(D0)
  按键板 GND    → 主控板 GND
  两板波特率均 9600

二、按键映射（单击 / 双击 / 三击，连击判定窗口 350ms）
------------------------------------------------------------
键1（D8）单击 → '1' 示教 / 记录点
          （第一次按进入示教模式；示教中再按记录当前点，最多 5 点）

键2（D9）单击 → '2' 暂停绘制（保持当前位置与任务状态）
          双击 → '3' 继续绘制（从暂停位置接续）

键3（D10）单击 → '4' 取消（终止当前绘制并回待机）
          双击 → '5' 折线绘制（示教 ≥2 点后，先回待机再自动按序连线）
          三击 → '6' 曲线绘制（示教 ≥3 点后，先回待机再自动绘制平滑曲线）

键4（D11）单击 → '7' 直线绘制演示（依序经过 6 个运动学坐标画直线）
          双击 → '8' 基础图形绘制（字母 N，21 个三维点依序经过）

三、常用操作流程
------------------------------------------------------------
画直线   ：单击键4（→'7'）
画字母 N ：双击键4（→'8'）
示教折线 ：单击键1 进入示教 → 摇杆移笔尖 → 单击键1 记录（最多 5 点）
         → 双击键3（→'5'）→ 回待机 → 自动按序画折线
示教曲线 ：同上记录 ≥3 点 → 三击键3（→'6'）→ 回待机 → 自动画曲线
绘制中控制：键2 单击 = 暂停；键2 双击 = 继续；键3 单击 = 取消

四、主控板串口调试指令（不接按键板时可在串口监视器手动输入）
------------------------------------------------------------
g = 直线演示     t = 示教 / 记录    s = 折线
c = 曲线         p = 暂停/继续切换  x = 取消      ? = 状态查询

五、注意事项
------------------------------------------------------------
1. 双击 / 三击要在 350ms 内完成连按；按慢了会被拆成多次单击。
2. 主控板舵机引脚（D9/D8/D7/D6）与按键引脚（D8~D11）互不冲突。
3. 绘图过程中夹爪保持闭合夹笔；取消/结束时回待机位。
