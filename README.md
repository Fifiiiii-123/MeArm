# MeArm 机械臂考核项目（算法·控制方向）

## 项目简介

基于 MeArm 机械臂套件的 Arduino 控制开发项目，对应机器人学院十二期二面「算法（控制、视觉）方向」考核任务：实现机械臂基础控制、串口指令通信、多舵机协同、夹取物体、按键录制/回放、运动学推导与轨迹绘制等功能。

## 硬件

- Arduino 主控板
- MeArm 机械臂套件（4 个舵机：底盘/后臂/前臂/钳子）
- 摇杆（JoyFK 系列）
- 4 按键板（KeypadBoard 系列）

## 目录结构

| 文件夹 | 说明 |

| angle/ | 舵机角度初始化调试 |
| Task1/ | 任务一：基础控制（关节独立移动） |
| Task1.1/、Task1.2/、Task1.3/、Task1.1.2/ | 基础控制迭代版本 |
| Task2/、Task2_alpha2/ | 任务二：夹取物体 A/B/C 并放置 |
| Task3/、Task3(1)/ | 任务三：按键循环触发夹取动作 |
| Task4/ | 任务四：运动学正解/逆解推导（含 README） |
| Task5/ | 任务五：轨迹绘制 |
| Task5_Line6 系列 | 直线绘制（含对齐、坐标轴修正调试） |
| Task5_LineN 系列 | 五点示教折线/平滑曲线绘制（含暂停/继续/取消、抬笔、示教方向等迭代） |
| JoyFK 系列 | 摇杆实时操控调试迭代 |
| KeypadBoard 系列 | 自制按键板输入调试迭代 |
| 任务五_四按键使用说明.txt | 任务五四按键操作说明 |
| 开发记录.md | 调试时间线（按日期记录开发/调试过程） |

## 开发与调试时间线

- **Git 提交历史**：`git log` 记录了代码的版本演进（开发/调试过程）
- **开发记录.md**：按日期补充每轮调试的详细过程（问题、解决、结果）

## 使用方法

用 Arduino IDE 打开对应任务文件夹中的 `.ino` 文件，选择正确的开发板型号与端口，编译上传即可。详细操作见各任务文件夹内的说明文档。
